# Whara Whara Guesthome

React/Vite website for Whara Whara Guesthome at `wharawhara.co.za`.

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Vercel Deployment

Use these settings when importing the GitHub repository into Vercel:

- Framework preset: `Vite`
- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`

After the first deployment, add `wharawhara.co.za` in the Vercel project domains panel and update the domain DNS records as Vercel instructs.
